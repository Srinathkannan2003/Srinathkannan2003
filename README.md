## About

I'm a multidisciplinary engineer who operates across the full spectrum of software — from large-scale enterprise platforms and SAP ecosystems to real-time data dashboards, browser-based games, and AI-powered tooling.

My work sits at the intersection of structure and creativity. I care about systems that are well-architected, interfaces that are well-crafted, and code that ages well. I don't specialize in a single domain by design — the most interesting engineering problems rarely respect boundaries.

Currently sharpening my work across enterprise application development, data engineering, and intelligent automation.

## Engineering Philosophy

Software is a craft that compounds. The decisions made early — in architecture, in naming, in abstraction — echo for years. I write code with the next engineer in mind, treat complexity as a cost to be justified, and approach new domains with the belief that fundamentals transfer.

I'm drawn to problems that sit at the edge of disciplines: where enterprise rigor meets product thinking, where data visualization becomes decision-making, where a game mechanic teaches you something about state management.

The best engineers I've studied aren't defined by their stack. They're defined by how they think.
